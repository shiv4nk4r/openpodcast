# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main` and the most recent GitHub Release tag when practical.

## Reporting a vulnerability

Please **do not** file a public GitHub issue for security bugs.

Email the maintainers or use GitHub **Private vulnerability reporting** on this repository:

1. Open the repo’s **Security** tab  
2. **Report a vulnerability**  
3. Include steps to reproduce, impact, and affected versions/platforms

We will acknowledge reports as soon as we can and coordinate a fix + disclosure.

## Scope notes

OpenPodcast is a desktop P2P studio. Reports involving invite ticket handling, local file paths, sidecar binaries (`ffmpeg`), or signing/release pipelines are especially appreciated.
