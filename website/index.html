What we’ve built

A Riverside-style flow that stays on your machines — from lobby to Premiere timeline.

Local HQ recording

Host and up to three guests each capture camera and mic locally. No streamed “master” that dies if someone’s Wi‑Fi dips.

Encrypted peer sync

Join with an invite ticket and studio password. Live traffic rides iroh over QUIC — encrypted in transit, direct on LAN or via relay.

Live studio stage

Roster, presence, preview frames, and screen share so the booth feels like you’re in the same room while files stay local.

Editor & layouts

Playback with presence-aware layouts, then compose a final cut or hand off to your NLE.

Premiere XML export

Ship a Final Cut Pro 7 XMEML package so Adobe Premiere can open your multi-track timeline with media linked.

On-device captions

Optional native speech-to-text on macOS and Windows — captions without uploading the episode to a third-party API.

How a session runs

Four beats from empty booth to editable tracks.

  1. Host a studio Create a session, set a password, share the invite.
  2. Admit guests They join, you let them in — max four people total.
  3. Record locally Everyone rolls on their own disk; you still hear each other live.
  4. Sync & export Tracks return to the host over P2P. Preview, render, or export XML.
